電池の基本原理と極板の決定法\n異なる2種類の金属板を電解質水溶液に浸して導線でつなぐと、電子の流れ（電流）が生じます。これが **化学電池** です。\n\n> **【極板決定の絶対ルール】**\n> - **イオン化傾向の「大きい」方の金属 $\\implies$ 負極（ふきょく）**（電子を放出する電極）\n> - **イオン化傾向の「小さい」方の金属 $\\implies$ $\\ce{H2SO4}$\n  - 負極の反応：$\\ce{Zn -> Zn^2+ + 2e-}$（亜鉛板が溶けて軽くなる）\n  - 正極の反応：$\\ce{2H+ + 2e- -> H2 ^}$（水溶液中の水素イオンが電子を受け取り、水素の泡が出る）\n- **欠点（分極：ぶんきょく）**：\n  正極の銅板の表面に水素の気泡 $\\ce{H2}$ **素焼き板（すやきいた）の2大役割**：\n  1. 2つの水溶液（$\\ce{ZnSO4}$ と $\\ce{CuSO4}$）が **直接急速に混ざり合うのを防ぐ**（混ざると銅が亜鉛板に直接析出して電池がショートする）。\n  2. **イオンを通過させて電気的中性を保ち、回路を完成させる**（負極側で増えすぎた陽イオン $\\ce{Zn^2+}$ が正極側へ、正極側で余った陰イオン $\\ce{SO4^2-}$ が負極側へと素焼き板の微細な孔を通って移動する）。\n\n---\n\n### 2. 【共テ新傾向】探究検量線（けんりょうせん）グラフの読解解法\n近年の共通テストでは、未知の機器分析（蛍光X線分析や分光光度計など）の実験データから検量線を用いて含有量を特定する探究問題が出題されます。\n\n> **【例題1】検量線を用いた元素含有率の計算**\n> 質量 $0.500\\,\\text{g}$ の合金試料を完全に酸に溶かし、全量を正確に $100\\,\\text{mL}$ とした。この溶液中の鉄 $\\ce{Fe}$ の濃度を測定するため、濃度既知の標準溶液を用いて検量線を作成したところ、以下の比例関係（検量線）が得られた。\n> 試料溶液の信号強度が **$48$** であったとき、この合金中の鉄の質量パーセント［$\\text{％}$］を求めよ。\n\n```\n信号強度\n   ▲\n60 ┼                  ●\n   │                ／\n48 ┼─ ─ ─ ─ ─ ─ ─ ● (試料)\n   │            ／│\n30 ┼          ●  │\n   │        ／    │\n 0 └───────┴─────┴────┴──► 鉄の濃度 [mg/L]\n   0      50     80   100\n```\n\n**【定石解法アルゴリズム】**\n- **ステップ1：検量線から目的の数値を正確に読み取る**\n  信号強度 $48$ の位置から横軸に視線を下ろすと、試料溶液中の鉄の濃度は **$80\\,\\text{mg/L}$** と読み取れる。\n- **ステップ2：溶液全体に含まれる元素の総質量を計算する**\n  溶液全体の体積は $100\\,\\text{mL} = 0.100\\,\\text{L}$ であるから、溶けている鉄の全質量は、\n  $$\\text{鉄の質量} = 80\\,\\text{mg/L} \\times 0.100\\,\\text{L} = 8.0\\,\\text{mg} = 0.0080\\,\\text{g}$$\n- **ステップ3：試料全体の質量で割って含有率（$\\text{％}$）を算出する**\n  $$\\text{鉄の質量パーセント} = \\frac{0.0080\\,\\text{g}}{0.500\\,\\text{g}} \\times 100 = 1.6\\,\\%$$\n  答：$1.6\\,\\%$\n\n---\n\n### 3. 【共テ思考力】気体発生に伴う元素含有率（％）の定性変化推論\n「混合物を加熱して気体が逃げたとき、残った物質中の各元素の割合（含有率［$\\text{％}$］）はどう変化するか？」という推論問題は、共通テストが極めて好む論点です。\n\n> **【例題2】アンモニア揮発に伴う窒素とリンの含有率変化**\n> 窒素 $\\ce{N}$、リン $\\ce{P}$、カリウム $\\ce{K}$ を含む固体の化成肥料がある。この肥料を加熱したところ、成分の一部が分解して気体のアンモニア $\\ce{NH3}$ のみが発生し、外部へ揮発（きはつ）して逃げていった。\n> 加熱後の固体残渣（ざんさ）における、**窒素 $\\ce{N}$ の含有率［$\\text{％}$］** および **リン $\\ce{P}$ の含有率［$\\text{％}$］** は、加熱前と比べてそれぞれどのように変化したか。「増加・減少・変化なし」から選べ。\n\n**【定石推論アルゴリズム】**\n含有率の定義式は常に分数です：\n$$\\text{着目元素の含有率}\\,[\\%] = \\frac{\\text{着目元素の質量}}{\\text{固体全体の全質量}} \\times 100$$\n「分母」と「分子」の動きを独立して追跡します。\n\n1. **分母（固体全体の全質量）の変化**：\n   気体である $\\ce{NH3}$ が外へ逃げていったため、固体全体の質量（分母）は確実に **減少** します。\n2. **分子（リン $\\ce{P}$ の質量）の変化**：\n   リン $\\ce{P}$ は揮発せず、すべて固体の中にそのまま残っています。つまり分子は **不変（一定）** です。\n   $$\\text{リンの含有率} = \\frac{\\text{一定}}{\\text{減少} \\downarrow} \\implies \\mathbf{増加する！}$$\n3. **分子（窒素 $\\ce{N}$ の質量）の変化**：\n   逃げていったアンモニア $\\ce{NH3}$（分子量 17）の中には、窒素 $\\ce{N}$（原子量 14）が $\\frac{14}{17} \\approx 82.4\\,\\%$ という極めて高い割合で含まれています。\n   もとの肥料中の窒素含有率（通常 $10 \\sim 20\\,\\%$ 程度）よりも遥かに窒素リッチな気体が抜け出ていくため、残った固体中の窒素の割合は激減します。\n   $$\\text{窒素の含有率} \\implies \\mathbf{減少する！}$$\n\n「逃げない元素の質量は変わらないが、全体の質量（分母）が減るため、その元素が占める割合（％）は見かけ上増える」という分数の論理を完璧に使いこなしましょう。\n\n---\n\n## 第3部：【共テ特有！実験器具・探究・正誤判定トラップ撃破】\n\n### 1. 実験器具と操作の理由\n\n#### ① 鉛 $\\ce{Pb}$ が希塩酸や希硫酸に溶けない理由\n- **現象**：鉛 $\\ce{Pb}$ はイオン化列で水素 $\\ce{H2}$ より前にある（$\\ce{Pb > H2}$）にもかかわらず、希塩酸や希硫酸に入れてもほとんど溶けません。\n- **理由**：反応した瞬間に、水に極めて溶けにくい不溶性の塩である **塩化鉛(II) $\\ce{PbCl2}$（白色）** や **硫酸鉛(II) $\\ce{PbSO4}$（白色）** の沈殿被膜が鉛の表面にびっしり張り付き、酸との接触を遮断してしまうからです。\n\n#### ② ダニエル電池を長持ちさせるための工夫\n共通テストの探究問題で頻出の操作です。\n- **硫酸亜鉛水溶液**：初めの濃度を **「薄く」** しておく（負極反応 $\\ce{Zn -> Zn^2+ + 2e-}$ が進みやすくするため）。\n- **硫酸銅(II)水溶液**：初めの濃度を **「濃く」** しておく（正極反応 $\\ce{Cu^2+ + 2e- -> Cu}$ で消費される $\\ce{Cu^2+}$ を十分に補給し続けるため）。\n\n---\n\n### 2. ⚠️ 受験生をハメる共通テストの罠！\n\n#### 罠①：電子の流れる向きと電流の向きの逆転罠\n- **引っかけ問題**：「電池の外部回路（導線）において、電子は正極から負極に向かって流れる。」\n- **真相**：**完全な誤り！**\n  - **電子（$\\text{e}^-$）の流れ**：**負極 $\\to$ 正極**（負極で金属が酸化されて電子を放出する）。\n  - **電流の流れ**：物理の定義上、電子の流れとは逆の **正極 $\\to$ 負極** です。\n
