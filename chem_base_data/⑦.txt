$a$、電離度を $\\alpha$ とすると、水素イオン濃度 $[\\text{H}^+]$ は次の掛け算一本で求まります。\n$$[\\text{H}^+] = c \\times a \\times \\alpha \\quad [\\text{mol/L}]$$\n- **モル濃度 $c$**：水の中に分子がどれくらい密集しているか\n- **価数 $a$**：分子1個あたり何本の \\times b \\times \\alpha \\quad [\\text{mol/L}]$$\n\n---\n\n### 2. 水の電離と「水のイオン積（$K_{\\text{w}}$）」\n実は、どんなに純粋な水であっても、ごくわずかに（1千万個に1個くらいの割合で）勝手に電離しています。\n$$\\ce{H2O <=> H+ + OH-}$$\nそして、$25\\,{}^\\circ\\text{C}$ の水溶液中では、酸性であってもアルカリ性であっても、**$[\\text{H}^+]$ と $[\\ce{OH-}]$ の掛け算の積が常に一定** に保たれるという驚くべき性質があります。\nこれを **水のイオン積（みずのいおんせき：記号 $K_{\\text{w}}$）** と呼びます。\n\n$$K_{\\text{w}} = [\\text{H}^+][\\ce{OH-}] = 1.0 \\times 10^{-14} \\quad [(\\text{mol/L})^2] \\quad (25\\,{}^\\circ\\text{C})$$\n\nこれは公園の **「シーソー」** と同じです。\n- 酸を入れて $[\\text{H}^+]$ を増やせば、バランスを取るために $[\\ce{OH-}]$ は自動的に激減する。\n- 塩基を入れて $[\\ce{OH-}]$ を増やせば、$[\\text{H}^+]$ は自動的に激減する。\n- 純粋な水（中性）のときは互いに同数なので、\n  $$[\\text{H}^+] = [\\ce{OH-}] = 1.0 \\times 10^{-7} \\quad [\\text{mol/L}]$$\n\n> **【塩基性水溶液での $[\\text{H}^+]$ の求め方】**\n> 先に $[\\ce{OH-}]$ を求めた後、水のイオン積を使って $[\\text{H}^+]$ に変換します。\n> $$[\\text{H}^+] = \\frac{1.0 \\times 10^{-14}}{[\\ce{OH-}]}$$\n\n---\n\n### 3. 水素イオン指数 $\\text{pH}$ の定義と読み取り法\n$[\\text{H}^+] = 0.00001\\,\\text{mol/L}$ のように小数をいちいち書くのは不便です。\nそこで、「$[\\text{H}^+]$ の指数のマイナスを取った数値」を **$\\text{pH}$（水素イオン指数）** と定義しました。\n\n$$[\\text{H}^+] = 1.0 \\times 10^{-\\text{pH}} \\quad [\\text{mol/L}]$$\n\n- $[\\text{H}^+] = 1.0 \\times 10^{-1}\\,\\text{mol/L} \\implies \\mathbf{\\text{pH} = 1}$（強い酸性）\n- $[\\text{H}^+] = 1.0 \\times 10^{-7}\\,\\text{mol/L} \\implies \\mathbf{\\text{pH} = 7}$（中性）\n- $[\\text{H}^+] = 1.0 \\times 10^{-13}\\,\\text{mol/L} \\implies \\mathbf{\\text{pH} = 13}$（強い塩基性）\n\n> **【直感ルール：$\\text{pH}$ が $1$ $\\text{pH}$ 計算の定石アルゴリズム（例題4パターン）\n\n#### パターンA：強酸の $\\text{pH}$（基本）\n> **【例題1】** $0.050\\,\\text{mol/L}$ の硫酸水溶液の $\\text{pH}$ を求めよ（電離度 $\\alpha = 1.0$ とする）。\n\n**【思考プロセス】**\n1. 硫酸 $\\ce{H2SO4}$ は より、$\\mathbf{\\text{pH} = 1}$\n\n#### パターンB：弱酸の $\\text{pH}$（電離度を掛ける）\n> **【例題2】** $0.10\\,\\text{mol/L}$ の酢酸水溶液（電離度 $\\alpha = 0.010$）の $\\text{pH}$ を求めよ。\n\n**【思考プロセス】**\n1. 酢酸 $\\ce{CH3COOH}$ は **1価の弱酸**（$a=1$）。\n2. $[\\text{H}^+] = c \\times a \\times \\alpha = 0.10 \\times 1 \\times 0.010 = 1.0 \\times 10^{-3}\\,\\text{mol/L}$\n3. 指数部分を見る：$10^{-\\mathbf{3}}$ より、$\\mathbf{\\text{pH} = 3}$\n\n#### パターンC：強塩基の $\\text{pH}$（$K_{\\text{w}}$ を経由する）\n> **【例題3】** $0.010\\,\\text{mol/L}$ の水酸化ナトリウム水溶液の $\\text{pH}$ を求めよ（$\\alpha = 1.0$ とする）。\n\n**【思考プロセス】**\n1. 水酸化ナトリウム $\\ce{NaOH}$ は **1価の強塩基**（$b=1, \\alpha=1.0$）。\n2. まず $[\\ce{OH-}]$ を求める：\n   $$[\\ce{OH-}] = 0.010 \\times 1 \\times 1.0 = 1.0 \\times 10^{-2}\\,\\text{mol/L}$$\n3. 水のイオン積 $K_{\\text{w}} = [\\text{H}^+][\\ce{OH-}] = 1.0 \\times 10^{-14}$ より、$[\\text{H}^+]$ を逆算する：\n   $$[\\text{H}^+] = \\frac{1.0 \\times 10^{-14}}{[\\ce{OH-}]} = \\frac{1.0 \\times 10^{-14}}{1.0 \\times 10^{-2}} = 1.0 \\times 10^{-12}\\,\\text{mol/L}$$\n4. 指数部分を見る：$10^{-\\mathbf{12}}$ より、$\\mathbf{\\text{pH} = 12}$\n\n#### パターンD：強酸の希釈計算\n> **【例題4】** $\\text{pH} = 2$ の塩酸 $10\\,\\text{mL}$ に純水を加えて $1000\\,\\text{mL}$ $100$ 倍になると、$\\text{pH}$ は $2$ だけ $7$ に近づく）\n\n---\n\n## 第3部：【共テ特有！実験器具・探究・正誤判定トラップ撃破】\n\n### 1. pH測定の実験器具と正しい操作\n\n#### ① pH試験紙の扱い方\n- **正しい操作**：清潔なガラス棒の先端に試料溶液を少量つけ、**ガラス棒をpH試験紙に軽く触れさせて液を少量移す**。その後、変色を比色表（ひしょくひょう）と比べる。\n- ⚠️ **絶対にやってはいけない誤操作**：**pH試験紙をビーカーの溶液の中にドボンと浸してはならない！**（試験紙に含まれる指示薬の色素が溶液中に溶け出し、試料溶液全体を汚染してしまうため）。\n\n#### ② pHメーター（pH計）の扱い方\n- ガラス電極を水溶液に浸して、電気的に高精度で $\\text{pH}$ を測定する器具。\n- **操作の理由**：測定の前後は、電極を **純水（蒸留水）でよく洗浄し、柔らかい吸水紙（キムワイプ等）で軽く水滴を拭き取る**。水滴が残っていると次の測定液が薄まり、拭き取り時に強く擦ると電極の薄いガラス膜が破損または帯電して正確な値が出なくなるため。\n\n---\n\n### 2. 実験安全の超頻出：濃硫酸の希釈法と理由\n濃硫酸（のうりゅうさん）を希釈して希硫酸を作るとき、実験手順の順序がセンター試験・共通テストで繰り返し問われています。\n\n> **【鉄則】「大量の水に、濃硫酸を少しずつかき混ぜながら加える」**\n> ❌ **絶対にやってはいけない危険操作**：「濃硫酸に水を注ぎ入れる」\n\n- **なぜ濃硫酸に水を注いではいけないのか？（理由の論理）**\n
