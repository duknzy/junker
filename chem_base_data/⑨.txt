酸化と還元・酸化数の決定ルール\n\n「酸化と還元って、酸素がくっつくことじゃないの？」「電子のやり取りになると、どっちが酸化でどっちが還元か頭が混乱する……」「酸化数の計算でプラスマイナスが逆になって大失点する……」\n酸・塩基と並び、共通テスト化学基礎の2大巨頭となるのがこの「酸化還元（さんかかんげん）」です。\n本講義では、初学者がつまずきやすい酸化・還元の定義の広がりを日常のたとえ話で整理し、酸化数を機械的に決定する黄金ルール、そして共通テストで頻出の滴定実験の盲点までを完全解説します。\n\n---\n\n## 第1部：【本質と直感イメージ】\n\n### 1. 酸化・還元の3つの定義（歴史のステップアップ）\n酸化と還元の定義は、化学の歴史とともに3段階に進化してきました。古い定義を捨てるのではなく、「より広い現象を説明できるように適用範囲を広げていった」と捉えましょう。\n\n| 定義の基準 | 酸化（さんか） | 還元（かんげん） | 特徴・守備範囲 |\n| :--- | :--- | :--- | :--- |\n| **① 酸素（$\\ce{O}$）の授受** | 酸素を **受け取る（化合する）** | 酸素を **失う（奪われる）** | 中学理科レベル。酸素が関わる反応しか説明できない。 |\n| **② 水素（$\\ce{H}$）の授受** | 水素を **失う（奪われる）** | 水素を **受け取る（化合する）** | 有機物などの反応に拡張。 |\n| **③ 電子（$\\text{e}^-$）の授受** | 電子を **失う（手放す）** | 電子を **受け取る（もらう）** | **【本質】** すべての反応を統一的に説明できる現代の定義。 |\n\n> **【直感たとえ話：電子は「お金（借金）」と同じ！】**\n> 電子はマイナスの電気（$\\text{e}^-$）を持っています。マイナスの電子を「借金」だとイメージしてください。\n> - **酸化**：電子（借金）を **手放す** $\\implies$ 懐がプラスに傾く（身軽になる）。\n> - **還元**：電子（借金）を **背負い込む** $\\implies$ 懐がマイナスに傾く（元気をなくす・元に戻る）。\n\n「還元」という言葉には「元の状態に戻る」という意味があります。酸化鉄などの金属酸化物から、奪われていた電子を取り戻してピカピカの単体金属へ「元通りに戻る」から還元と呼ぶのです。\n\n---\n\n### 2. 「酸化数（さんかすう）」の正体と役割\n共有結合（きょうゆうけつごう）のように電子が完全に移動していない分子（$\\ce{H2O}$ や $\\ce{CO2}$ など）では、「誰が電子を手放し、誰が電子をもらったのか」がパッと見ではわかりません。\nそこで化学者が作った架空のスコア（ものさし）が **酸化数** です。\n\n- **酸化数とは**：\n  「もし結合している電子対を、電気陰性度（でんきいんせいど：電子を引っ張る力）が強い方の原子がひとり占めしたと仮定したとき、その原子が帯びる仮想的な電荷」のこと。\n\n酸化数を使うことで、次の一発判定ルールが手に入ります。\n- **酸化数が増加した**（プラス側へ動いた） $\\implies$ 電子を失ったので **「酸化された」**\n- **酸化数が減少した**（マイナス側へ動いた） $\\implies$ 電子をもらったので **「還元された」**\n\n---\n\n### 3. 酸化数を絶対に間違えない「優先決定ルール」\n酸化数を求めるときは、気まぐれに決めるのではなく、**次の「絶対的優先順位」にしたがって機械的に割り振る** のが鉄則です。\n\n```\n【酸化数決定の優先ピラミッド】\n【ルール1】単体の酸化数はすべて「0」！\n【ルール2】化合物中の F は常に「-1」！ 1族元素(Li, Na, K)は「+1」！ 2族元素(Mg, Ca, Ba)は「+2」！ Al は「+3」！\n【ルール3】化合物中の H は原則「+1」！（※例外あり）\n【ルール4】化合物中の O は原則「-2」！（※例外あり）\n【ルール5】化合物全体での酸化数の合計は「0」、多原子イオン全体での合計は「イオンの価数」！\n```\n\n#### 原則の手順（ステップ）\n1. **単体（1種類の元素だけでできた純物質）**：どんな物質でも **必ず $0$**。\n   - 例：$\\ce{O2}, \\ce{H2}, \\ce{Fe}, \\ce{C}, \\ce{Cu}, \\ce{N2}, \\ce{O3}, \\ce{S8}$ $\\implies$ すべて **$0$**\n2. **単原子イオン**：そのイオンの電荷がそのまま酸化数。\n   - 例：$\\ce{Na+}$ は $+1$、$\\ce{Cu^2+}$ は $+2$、$\\ce{Cl-}$ は $-1$、$\\ce{Al^3+}$ は $+3$\n3. **化合物中の各原子**：\n   - **$\\ce{H}$ は原則 $+1$**\n   - **$\\ce{O}$ は原則 $-2$**\n   - 1族（アルカリ金属 $\\ce{Na, K}$）は必ず $+1$、2族（アルカリ土類金属 $\\ce{Ca, Ba}$ や $\\ce{Mg}$）は必ず $+2$\n4. **合計値のつり合い**：\n   - **電気的に中性な化合物**：構成原子の酸化数の総和は **$0$**。\n   - **多原子イオン**：構成原子の酸化数の総和は **そのイオンの電荷**。\n\n#### ⚠️ 共通テストで狙われる2大例外！\n共通テストは「原則」だけでなく「例外」を突いてきます。次の2つは必暗記です。\n\n1. **過酸化水素 $\\ce{H2O2}$ 中の $\\ce{O}$ の酸化数は「$-1$」**\n   - 理由：$\\ce{H}$ が $+1$ であるルールが優先されます。$\\ce{H}$ が2個で $+2$ なので、化合物全体で $0$ になるためには、$\\ce{O}$ 2個で $-2$、すなわち **$\\ce{O}$ 1個あたり $-1$** となります。\n2. **水素化ナトリウム $\\ce{NaH}$ などの金属水素化物中の $\\ce{H}$ の酸化数は「$-1$」**\n   - 理由：アルカリ金属である $\\ce{Na}$ が $+1$ であるルールが最優先されます。したがって、相手の $\\ce{H}$ は引き算で **$-1$** にならざるを得ません。\n\n---\n\n## 第2部：【頻出計算と定石解法アルゴリズム】\n\n### 1. 酸化還元反応かどうかの瞬殺判定法\n問題文に並んだ複数の化学反応式を見て、「酸化還元反応をすべて選べ」と問われたら、次の2段階アルゴリズムで解きます。\n\n> **【瞬殺アルゴリズム】**\n> - **第1段階：式の中に「単体」があるか探す！**\n> 3. 代表的な酸化剤・還元剤の半反応式（はんはんのうしき）\n- **酸化剤（さんかざい）**：相手を酸化する物質 $\\implies$ **自分自身は電子を受け取って「還元」される**。\n- **還元剤（かんげんざい）**：相手を還元する物質 $\\implies$ **自分自身は電子を手放して「酸化」される**。\n\n#### ① 代表的な酸化剤の半反応式（酸性水溶液中）\n1. **過マンガン酸カリウム（$\\ce{KMnO4}$）**：\n   $$\\ce{MnO4- + 8H+ + 5e- -> Mn^2+ + 4H2O}$$\n   マンガン $\\ce{Mn}$ の酸化数：$+7$（赤紫色）$\\to +2$（ほぼ無色・淡桃色）\n2. **二クロム酸カリウム（$\\ce{K2Cr2O7}$）**：\n   $$\\ce{Cr2O7^2- + 14H+ + 6e- -> 2Cr^3+ + 7H2O}$$\n   クロム $\\ce{Cr}$ の酸化数：$+6$（赤橙色）$\\to +3$（緑色）\n3. **濃硝酸（$\\ce{HNO3}$）**：\n   $$\\ce{HNO3 + H+ + e- -> NO2 + H2O}$$\n   窒素 $\\ce{N}$ の酸化数：$+5 \\to +4$（二酸化窒素：赤褐色気体）\n4. **希硝酸（$\\ce{HNO3}$）**：\n   $$\\ce{HNO3 + 3H+ + 3e- -> NO + 2H2O}$$\n   窒素 $\\ce{N}$ の酸化数：$+5 \\to +2$（一酸化窒素：無色気体）\n\n#### ② 代表的な還元剤の半反応式\n1. **シュウ酸（$\\ce{(COOH)2}$）**：\n   $$\\ce{(COOH)2 -> 2CO2 + 2H+ + 2e-}$$\n   炭素 $\\ce{C}$ の酸化数：$+3 \\to +4$\n2. **硫化水素（$\\ce{H2S}$）**：\n   $$\\ce{H2S -> S + 2H+ + 2e-}$$\n   硫黄 $\\ce{S}$ の酸化数：$-2 \\to 0$（単体の硫黄の淡黄色沈殿）\n3. **鉄(II)イオン（$\\ce{Fe^2+}$）**：\n   $$\\ce{Fe^2+ -> Fe^3+ + e-}$$\n   鉄 $\\ce{Fe}$ の酸化数：$+2 \\to +3$\n\n#### ③ 相手によって酸化剤にも還元剤にもなる「二刀流」物質\n- **過酸化水素 $\\ce{H2O2}$**：\n  - 原則は **酸化剤** として働く：\n    $$\\ce{H2O2 + 2H+ + 2e- -> 2H2O}$$\n  - より強力な酸化剤（$\\ce{KMnO4}$ など）の前ではやむを得ず **還元剤** として働く：\n    $$\\ce{H2O2 -> O2 + 2H+ + 2e-}$$\n- **二酸化硫黄 $\\ce{SO2}$**：\n  - 原則は **還元剤** として働く：\n    $$\\ce{SO2 + 2H2O -> SO4^2- + 4H+ + 2e-}$$\n  - より強力な還元剤（$\\ce{H2S}$ など）の前では **酸化剤** として働く：\n    $$\\ce{SO2 + 4H+ + 4e- -> S + 2H2O}$$\n\n---\n\n### 4. 半反応式から全体の化学反応式をつくる3ステップ\n\n> **【例題】硫酸酸性の過マンガン酸カリウム水溶液と過酸化水素水の反応**\n\n- **ステップ1：半反応式の電子 $\\text{e}^-$ の数を最小公倍数で揃えて足し合わせる**\n  - 酸化剤：$\\ce{MnO4- + 8H+ + 5e- -> Mn^2+ + 4H2O}$　……①（$\\times 2$）\n  - 還元剤：$\\ce{H2O2 -> O2 + 2H+ + 2e-}$　……②（$\\times 5$）\n  電子の数を $10\\text{e}^-$ で揃えて両辺を足します：\n  $$2\\ce{MnO4-} + 16\\ce{H+} + 10\\text{e}^- + 5\\ce{H2O2} \\to 2\\ce{Mn^2+} + 8\\ce{H2O} + 5\\ce{O2} + 10\\ce{H+} + 10\\text{e}^-$$\n\n- **ステップ2：両辺の $\\text{e}^-$ と $\\ce{H+}$ を相殺（整理）して「イオン反応式」を完成させる**\n  $$2\\ce{MnO4- + 6H+ + 5H2O2 -> 2Mn^2+ + 8H2O + 5O2}$$\n\n- **ステップ3：反応に関与していない「傍観イオン」を両辺に補って「完全な化学反応式」にする**\n  左辺の $2\\ce{MnO4-}$ の相棒としてカリウムイオン $2\\ce{K+}$、および $6\\ce{H+}$ の相棒として硫酸イオン $3\\ce{SO4^2-}$（硫酸 $3\\ce{H2SO4}$ 分）を両辺に加えます。\n  $$\\mathbf{2\\ce{KMnO4} + 5\\ce{H2O2} + 3\\ce{H2SO4} \\to 2\\ce{MnSO4} + 5\\ce{O2} + 8\\ce{H2O} + \\ce{K2SO4}}$$\n\n---\n\n## 第3部：【共テ特有！実験器具・探究・正誤判定トラップ撃破】\n\n### 1. 過マンガン酸カリウム滴定の実験器具と「理由」の論理\n\n#### ① なぜ指示薬（フェノールフタレイン等）を一切加えないのか？\n- **理由**：**過マンガン酸カリウム自身が強烈な赤紫色をしているから（自己指示薬）**。\n- **滴定の様子**：\n  三角フラスコ内の還元剤（過酸化水素など）に $\\ce{KMnO4}$ 水溶液を滴下していくと、反応している間は $\\ce{MnO4-}$（赤紫）が $\\ce{Mn^2+}$（無色）に変わるため、滴下した瞬間に赤紫色が消えて無色になります。\n- **終点の見極め**：\n  フラスコ内の還元剤がすべて反応し尽くした瞬間、次に滴下したわずか1滴の $\\ce{MnO4-}$ が反応できずにそのまま残ります。\n  したがって、**「滴下した液のわずかな赤紫色が、振り混ぜても消えずに残るようになった瞬間」** が滴定の終点です。\n\n#### ② なぜ「褐色ビュレット」を用いるのか？\n- **理由**：過マンガン酸カリウムは光によって徐々に分解する性質（感光性）があるため、**遮光して分解を防ぐ目的で褐色（かっしょく）のガラス器具を使用** します。\n\n#### ③ なぜ「希硫酸」で酸性にするのか？（塩酸や硝酸がダメな理由）\n共通テストで極めて頻出の実験理由問題です。\n- ❌ **塩酸（$\\ce{HCl}$）を使ってはいけない理由**：\n  塩酸に含まれる塩化物イオン $\\ce{Cl-}$ 自身が還元剤として働き、$\\ce{KMnO4}$ によって酸化されて有毒な塩素 $\\ce{Cl2}$ が発生してしまうため（過マンガン酸カリウムが無駄に消費されて測定値が狂う）。\n- ❌ **硝酸（$\\ce{HNO3}$）を使ってはいけない理由**：\n  硝酸自身が強力な酸化剤であるため、フラスコ内の還元剤と硝酸が反応してしまい、過マンガン酸カリウムの滴下量が狂ってしまうため。\n- ⭕ **希硫酸（$\\ce{H2SO4}$）を使う理由**：\n  硫酸イオン $\\ce{SO4^2-}$ は、この条件下で酸化も還元もされず極めて安定しているため、余計な副反応を起こさないから。\n\n---\n\n### 2. ⚠️ 受験生をハメる共通テストの罠！\n\n#### 罠①：主語と述語の逆転罠（「酸化された」と「酸化剤」）\n- **引っかけ選択肢**：「ある反応において、物質Aは酸化されたので、酸化剤として働いた。」\n- **真相**：**完全な誤り！**\n  - 相手を酸化する物質 $\\implies$ **酸化剤**（自分自身は **還元** される）\n  - 相手を還元する物質 $\\implies$ **還元剤**（自分自身は **酸化** される）\n  「自分が酸化された」なら、相手を還元したことになるので「還元剤」です。主語が「作用」なのか「自身の変化」なのかを問題文で必ず二重線で確認してください。\n\n####
