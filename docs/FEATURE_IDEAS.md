# Flora / junker 機能構想メモ

## 🕵️‍♂️ 新機能アイデア：答案監察医モード（エラー・フォレンジック / 誤答捜査）

### 1. コンセプト
「答えを教わる」「解説を読む」受動的な授業ではなく、生徒自身が**「答案の監察医 / 探偵」**となり、**「ある架空の生徒が書いたリアルな誤答答案」の論理破綻箇所を暴いて修正する**実践的アクティブラーニング機能。
junkerの原点である「誤答克服・トラップ分析」に最も直結する学習スタイル。

---

### 2. 学習フロー（UI/UX設計イメージ）
1. **事件発生（問題と誤答答案の提示）**
   - 画面上部に問題文、中央に「架空の生徒A君の途中式・答案」が表示される。
   - 答案は一見きれいに解けているように見えるが、どこかに受験生が最もハマりやすい「典型的な落とし穴」が仕組まれている。
   - （例：物理で外力と動摩擦力の向きを逆にした、数学で $x=0$ の場合分けを忘れて両辺を割った、化学でビュレットを水洗いして濃度が変わった 等）
2. **現場検証・容疑箇所の特定（インタラクティブ操作）**
   - 生徒は答案の怪しい行（ステップ）をタップして選択、またはチャットで「〇行目の式変形で、前提条件の〇〇を見落としている」と指摘する。
3. **AI監察官の講評 ＆ 解決**
   - 正しく見破れた場合：
     - AI「見事！まさにそこが最大の落とし穴。なぜ多くの受験生がこのミスを犯すのか、出題者の心理を暴こう」
     - 正しい解法と、落とし穴を回避するための「思考のチェックリスト」を提示。
   - 見当違いの場合：
     - 「その行は合っているよ。もっと手前の『前提条件』をよく観察してみて」と捜査のヒントを出す。
4. **junkerエコシステムとの連携**
   - 暴いた罠がそのまま「トラップカード」「暗記カード（Insights）」「誤答ノート」に1タップで登録され、復習スプリントに出題される。

---

### 3. 科目別の典型事件簿（出題例）
* **数学**:
  - 2乗展開時の同値性の崩れ（無縁根の混入）
  - 相加相乗平均の「等号成立条件」の確認忘れ
  - 円順列・数珠順列での対称性の重複カウント
* **物理**:
  - 静止摩擦力を勝手に $\mu N$ と置いて立式した事件
  - 物体を投げ上げたときの加速度の符号（正負）の逆転
  - 浮力の $\rho$ を液体の密度ではなく物体の密度にした事件
* **化学**:
  - 弱酸遊離反応で強酸と弱酸の力関係を見誤った事件
  - 中和滴定でビュレットを純水で洗ってそのまま滴定した事件
* **英語**:
  - 関係代名詞 that と接続詞 that の文構造混同
  - 仮定法過去完了の「もしあの時〜だったら、今頃は…」の時制ズレ
